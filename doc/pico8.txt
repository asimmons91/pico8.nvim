*pico8.nvim* *pico8*

Neovim client for pico-lsp, a PICO-8 language server.

==============================================================================
SETUP                                                         *pico8-setup*

Call: >lua
    require("pico_lsp").setup()
<
The default setup enables the `pico_lsp` client for `pico8` buffers and starts
the helper for cart-owned `.lua` files. The shipped config is loaded from
`lsp/pico_lsp.lua` on 'runtimepath'; loading it also registers the cached cart
statusline module and its commands (see |pico8-statusline|).

`.p8` buffers use the cart's directory as the workspace root, even outside a
git repository. Carts in different directories use separate clients. Override
`root_dir` with `vim.lsp.config("pico_lsp", { ... })` before opening a cart
for repository-wide symbols.

A loaded cart buffer is the helper's include source. Reload an open cart with
`:edit!` after an external change; the helper rescans on reload.
`:Pico8Refresh` clears cached include data and rescans loaded `.lua` buffers;
it does not reload a cart buffer. The helper only detaches attachments it
created; a client started by the user is left alone.

Options:
    `cmd`           server command (string, list, or function)
    `lsp`           enable the client during setup (default true)
    `disable`       disable the helper and LSP setup
    `codelens`      enable client-side budget lens display (default true)
    `inlay_hints`   enable client-side inlay-hint display (default true)
    `settings`      pico8 server settings table

The shipped config enables the client-side display for the cart budget lens
and inlay hints on `pico8` buffers. The server's `pico8.limits.codeLens` and
`pico8.inlayHints` settings decide what is returned; hints also require type
checking to be enabled. See the pico-lsp configuration reference for defaults.
Client-side options apply to clients started afterwards. Restart Neovim after
changing server settings; `:lsp restart` on Neovim 0.12+ is enough for the
display options.
`:Pico8ToggleInlayHints` toggles the display for a buffer and warns when the
server setting is false or absent.

The server owns setting defaults; the plugin does not duplicate them. The
command falls back from `g:pico_lsp_cmd` to `$PICO_LSP_BIN` to `pico-lsp`.

A lazy.nvim spec: >lua
    { "asimmons91/pico8.nvim", main = "pico_lsp", lazy = false, opts = {} }
<

STATUSLINE                                                 *pico8-statusline*

The helper caches `pico8/cartInfo` for a root cart, an included `.lua` buffer,
or a decoded `.p8.png` buffer: >lua
    local api = require("pico_lsp")
    api.cart_status()            -- cached text, or nil before the first response
    api.cart_info()              -- full cached cartInfo table
    api.refresh_cart_info()      -- asynchronous refresh
<
`cart_status()` only reads the cache and never blocks on the server. It updates
after an attach, `:w`, `InsertLeave`, and a 500 ms edit debounce. The compressed
segment is omitted when `compressedStatus` is `unavailable`, as it is for
standalone `.lua` carts. Pass `{ fields = { "tokens", "chars" } }` to select
segments.

A dependency-free statusline example: >lua
    function _G.Pico8CartStatus()
      return require("pico_lsp").cart_status() or ""
    end
    vim.o.statusline = "%f %m %{%v:lua.Pico8CartStatus()%} %= %l:%c"
<
`cart_info().compressedStatus` is `ok`, `warning`, `error`, or `unavailable`.
Statusline plugins can use it to color the component. A lualine recipe is in
`README.md`.

COMMANDS                                                   *pico8-commands*

:Pico8OpenPng [path]     Decode a `.p8.png` cart into a read-only buffer.
:Pico8ReloadPng          Reload the current decoded PNG cart.
:Pico8InsertGlyph [name] Insert a P8SCII glyph or open the picker.
:Pico8Refresh            Clear the include cache and rescan loaded buffers.
:Pico8ToggleInlayHints   Toggle client-side inlay hints for this buffer.
:Pico8CartInfo           Request and show the cart budget with file detail.
:Pico8Tabs               Pick a code tab and jump to its start line.

`:Pico8Tabs` explains that tabs belong to the owning cart on an included `.lua`
buffer, and jumps inside the virtual buffer for a decoded `.p8.png` cart.

Proposed commands: `:Pico8OpenCart` and `:Pico8InstallParser`.

==============================================================================
VARIABLES                                                 *pico8-variables*

`g:pico8_glyph_maps`     Enable Shift-A..Shift-Z glyph maps.
`g:pico_lsp_cmd`         Override the server command.
`g:pico_lsp_helper_disabled` Disable the included `.lua` helper.
